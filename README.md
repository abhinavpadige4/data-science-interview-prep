## 🚀 How to Use This Repo

1. **Read `01_study_plan.md`** — commit to the 7-day schedule.
2. **Skim `02_top_resources.md`** — pick 1–2 deep resources per topic.
3. **Solve problems in `solutions/`** — read the problem, try it yourself, then compare with the reference solution.
4. **Score yourself with `03_quality_scoring.md`** — target ≥ 80 before the interview.
5. **Do `mock_interview/questions.md`** the day before.

## ⏱ Time Budget (per day)

- **4 hours** focused study + problem solving
- **1 hour** review + flashcards
- **1 hour** mock interview / system design practice
