# Top Resources for Data Science Interviews

Curated, high-signal resources. Pick **1–2 per topic** — don't try to consume everything.

---

## 🐍 Python

### Books
- **"Fluent Python" (2nd ed.) — Luciano Ramalho** — the definitive deep-dive.
- **"Python Cookbook" (3rd ed.) — David Beazley** — practical recipes.
- **"Effective Python" — Brett Slatkin** — 90 best practices.

### Practice
- **LeetCode** — filter by "Array", "Hash Table", "Two Pointers", "Sliding Window".
- **HackerRank** — "Python" track for syntax fluency.
- **Codewars** — kata 6kyu–4kyu for algorithmic thinking.

### Blogs / Articles
- Real Python (realpython.com) — tutorials.
- "Python Tricks" newsletter by Dan Bader.

---

## 📊 Statistics & Probability

### Books
- **"Statistical Inference" — Casella & Berger** — rigorous, grad-level.
- **"All of Statistics" — Larry Wasserman** — concise, modern.
- **"Think Stats" — Allen Downey** — Python-first, beginner-friendly.
- **"Bayesian Data Analysis" — Gelman et al.** — the Bayesian bible.

### Courses
- **Khan Academy — Statistics & Probability** (free).
- **Coursera: "Statistics with Python" — University of Michigan**.
- **MIT 6.041 — Introduction to Probability** (free on YouTube).

### Blogs
- **Distill.pub** — visual, conceptual ML/stats explainers.
- **Towards Data Science** — search "A/B testing pitfalls".

---

## 🤖 Machine Learning

### Books
- **"Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow" — Aurélien Géron** — the practical standard.
- **"The Elements of Statistical Learning" — Hastie, Tibshirani, Friedman** — the theoretical standard.
- **"An Introduction to Statistical Learning" — James et al.** — gentler intro to ESL.
- **"Deep Learning" — Goodfellow, Bengio, Courville** — the DL bible (free online).

### Courses
- **Andrew Ng's ML Specialization** (Coursera) — foundational.
- **Stanford CS229** (YouTube) — rigorous ML theory.
- **fast.ai Practical Deep Learning** (free) — top-down DL.
- **H2O.ai XGBoost course** — gradient boosting deep-dive.

### Papers to Read
- "A Generalized Linear Model for Boosting" (Friedman, 2001) — GBDT.
- "XGBoost: A Scalable Tree Boosting System" (Chen & Guestrin, 2016).
- "Attention Is All You Need" (Vaswani et al., 2017).
- "BERT: Pre-training of Deep Bidirectional Transformers" (Devlin et al., 2018).

## 🗄 SQL

### Books
- **"SQL Antipatterns" — Bill Karwin** — what NOT to do.
- **"SQL Performance Explained" — Markus Winand** — query optimization.

### Practice
- **LeetCode SQL** — 150+ problems, filter by difficulty.
- **HackerRank SQL** — "Advanced Select" track.
- **StrataScratch** — real-world SQL problems (paid, but worth it).
- **SQLZoo** — interactive basics.

### Blogs
- **Use The Index, Luke!** (use-the-index-luke.com) — query plans.
- **Mode Analytics SQL Tutorial** — free, practical.
